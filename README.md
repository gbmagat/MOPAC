# MOPAC | Museum of Philippine Arts and Culture

My first responsive website project, showcasing the Museum of Philippine Arts and Culture (MOPAC) in Pampanga. It brings together museum information, exhibition galleries, artwork highlights, and visitor details in a multi-page website built with HTML, CSS, and JavaScript.

**[Visit the live website](https://gbmagat.github.io/MOPAC/)**

## Features

- Video introduction and featured artwork on the homepage.
- Exhibition pages covering the Mabini Art Movement, 13 National Artists, and cultural artifacts.
- Visitor information with an embedded Google Maps location.
- Responsive layouts and a mobile navigation menu.
- Homepage search for artwork highlights, powered by jQuery.

## Tech stack

- **HTML** for page structure and content.
- **CSS** for styling, responsive layouts, and navigation.
- **JavaScript and jQuery** for homepage search interactions.
- **GitHub Pages** for hosting.
